# Automatic-save filenames and separate manual history

Source `30fa66b21914b82ea048afdd5cfd5122cbd5d70f` separates the last manual-save folder from the configured automatic-save folder, with an independent persisted key and backwards-compatible default. MainWindow uses the tested policy functions for both paths. A manual save cannot redirect future automatic saves.

Automatic saving requires an absolute configured folder, an incoming Ready transfer with no error and verified trust. Rejected names stay available for manual saving. Conservative basename rules refuse leading dots/whitespace, trailing dots/whitespace, separators, control/format characters, Windows-invalid characters and alternate streams, reserved device stems even with extensions, including superscript COM/LPT digits, and names exceeding the protocol's 255 UTF-8 bytes. Supplementary Unicode names also fail closed under this conservative policy. Ordinary BMP Unicode names remain supported. Windows namespace rules are checked against [Microsoft's file-naming documentation](https://learn.microsoft.com/en-us/windows/win32/fileio/naming-a-file).
