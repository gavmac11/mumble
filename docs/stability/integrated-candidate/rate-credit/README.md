# Shared file-transfer sending rate

One elapsed-time credit pool charges complete ciphertext chunks across active sends. Round-robin dispatch shares the budget, paused callbacks have capped bursts, and unlimited dispatch yields after bounded batches. Cancellation during chunk/completion callbacks cannot turn an aborted job into Saved or stop an unrelated sender. The UI describes the combined rate.

The original c80433c2 revision has four failing rate negative controls and 40 passing Mac suites in 49.15 seconds. Its strict native Windows build and 39 transfer cases pass. [Revision 4eb2e56](revision-4eb2e56/validation.json) fixes callback cancellation and pause bursts, with proven failing negative controls, 40 Mac suites in 55.82 seconds and 42 native Windows transfer cases. Both exact Opus 5.5 CLI reviews of those revisions are retained there; the second identified fractional-time credit loss, unchanged-configuration resets and slow large chunks.

[Revision 4f30bc5](revision-4f30bc5/validation.json) retains nanosecond elapsed time and division remainders, preserves earned credit on unchanged rates, and selects smaller protocol-valid chunks for new slow sends. All three regressions fail against old 4eb production and pass after repair. Both slow transfers save byte-for-byte originals with a 700 ms receiver idle limit; the repeated configuration fixture refreshes every 80 ms. Frequent refill calls prove elapsed time survives sub-millisecond accounting. Fourteen focused cases and all 40 enabled Mac suites pass (58.14 seconds), with strict full Release client/server builds. The final focused Opus 5.5 CLI review found no further must-fix defect in these three corrections. Its possible non-KiB-aligned chunk concern was checked against the unchanged manifest decoder: any integer within protocol bounds is accepted. Native Windows exact-source qualification is pending.

Concurrent loopback jobs both reach Ready and save exact original bytes. An earlier handshake fixture was corrected to count active timers; no production timeout or assertion was relaxed. An earlier weaker pause fixture passed before repair and is explicitly excluded from failing negative-control claims.

These results qualify engine ciphertext pacing. Server negotiation/refusal, recipient acknowledgements, GUI/TLS queue bounds and slow healthy receivers remain open. Outer protocol/TLS overhead is excluded. Fairness is per chunk; existing signed manifests cannot shrink after rate reduction, and extreme low-rate concurrency can still exceed receiver idle limits. Initial root logs/validation retain their c804 source; later records remain source-specific. OverlayTest is disabled throughout.
